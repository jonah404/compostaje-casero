# Huerta: cultivos con ciclo de vida, catálogo y calendario — Plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Agregar la huerta: cultivos (anuales y perennes) con catálogo de 24 especies, ciclo de vida calculado, tareas en "Hoy" y un área "🥬 HUERTA" en el evento diario del calendario.

**Architecture:** Cada cultivo es una planta más (misma colección `plantas`, misma hoja "Plantas", campos nuevos, columnas U–AF). El catálogo y las funciones puras viven en un módulo ES aparte (`huerta-catalogo.js`), probado en Node. Al agregar un cultivo se copia una **foto del perfil** al registro, así Apps Script (que no conoce el catálogo) solo lee columnas. `estPlanta` obtiene el perfil de una única función `perfilDePlanta`.

**Tech Stack:** HTML/CSS/JS vanilla (módulo ES en `index.html` + módulo `huerta-catalogo.js`), Firebase Firestore 10.12, Google Apps Script (ES5), Node 24 para las pruebas (`node:assert`, `vm`), Firebase Hosting.

**Spec:** `docs/superpowers/specs/2026-09-30-huerta-design.md`

## Global Constraints

Copiadas del spec:

- Los cultivos viven en la **misma colección `plantas`** con campos nuevos; las plantas existentes tienen `categoria` vacía y **no cambian de comportamiento**.
- Campos y columnas del Sheet (hoja "Plantas", a continuación de "Notas"=T): U `categoria`, V `cultivo`, W `ciclo`, X `fechaTrasplante`, Y `riegoVerano`, Z `riegoInvierno`, AA `diasFert`, AB `diasPlagas`, AC `diasATrasplante`, AD `diasACosecha`, AE `estadoCultivo`, AF `fechaCierre`. La fecha de siembra es el `fechaP` existente.
- **Perfil único:** `perfilDePlanta(p)`; si `p.categoria === 'huerta'` devuelve `{ tipo:'Exterior', riegoVerano, riegoInvierno, diasFert, fertMesIni:null, fertMesFin:null, tempMin:null, podaDias:null }` desde su foto; si no, `perfilEspecie(...)`.
- Catálogo en `public/public/huerta-catalogo.js` (módulo ES) con **24 especies**: lechuga, acelga, espinaca, rúcula, repollo, brócoli, tomate, morrón, berenjena, zapallito, zapallo, pepino, choclo, zanahoria, remolacha, cebolla de verdeo, albahaca, perejil, cilantro, menta, orégano, romero, tomillo, frutilla. La ficha usa el mismo formato que `FITOSANITARIO`; para un cultivo la ficha se busca por `p.cultivo` (clave), no por nombre; los `'manual'` no tienen ficha.
- Fases: `semillero | por-trasplantar | crecimiento | cosecha-proxima | cosecha | cerrado`, con la fórmula del spec (perenne o sin `diasACosecha` → `crecimiento`; con `diasATrasplante` y sin `fechaTrasplante`: `d < diasATrasplante` → `semillero`, si no `por-trasplantar` con prioridad sobre cosecha; `d >= diasACosecha` → `cosecha`; `d >= diasACosecha - 7` → `cosecha-proxima`; si no `crecimiento`).
- "Hoy": sección **🥬 Huerta** entre Plantas y Pecera; cerrados no generan tareas ni alerta de helada. Tareas: `riego-huerta` (una sola, ✓ registra `💧 Riego` en cada cultivo listado), `trasplante-<id>` (✓ guarda `fechaTrasplante = hoy` y evento `🌱 Trasplante`), `fert-<id>` y `plagas-<id>` (› mini formulario), `cosecha-<id>` (› confirmación "Cosechado"; solo anuales; silenciada 3 días tras un evento `🍂 Cosecha`; 7 días antes va a "Próximos"). Mismo guardado diferido de 5 s con Deshacer.
- Cierre: **Cosechado** (`estadoCultivo='cosechado'`, `fechaCierre=hoy` y evento `🍂 Cosecha`), **Terminar** (`'terminado'`, `fechaCierre=hoy`, sin evento). Historial colapsado en la pestaña Huerta.
- Riego: la lluvia ≥ 8 mm cuenta como riego (lógica existente de `aguaEfectiva`).
- Apps Script: ES5 (sin `const`/`let`/flechas/plantillas), `guardarPlantaSheet` y `sincronizarPlantasAFirestore` cubren U–AF, `agregarColumnasHuerta()` (una sola vez), `actualizarFichaPlantas` usa la foto y saltea cerrados, `verificarEventosPlantas` ignora cultivos salvo para helada, `verificarEventosHuerta()` nueva, `EVENTO_UNICO.areas` suma `{ id:"huerta", encabezado:"🥬 HUERTA" }` después de plantas, `testHuerta()` sin tocar el calendario.
- Service worker: `huerta-catalogo.js` en `APP_SHELL` y caché `compost-tracker-v3`.
- Botones y filas ≥ 44px; texto secundario ≥ 12px (cabeceras de tablas densas: 11px).
- Identidad visual intacta (paleta tierra, DM Serif Display / DM Sans, modo oscuro).
- Verificación en el navegador con `?dry=1`, vista de celular (375px), **sin escrituras a datos reales**. Las pruebas de lógica corren en Node.
- **Orden de despliegue:** el usuario pega `codigo.gs` y corre `agregarColumnasHuerta()` **antes** de publicar la app. Merge a `main` y push al final.

## Decisiones del plan (detalles que el spec no fijaba)

1. **Defaults del perfil** si falta un dato (solo cultivos manuales mal cargados): `riegoVerano 3, riegoInvierno 5, diasFert 30, diasPlagas 7`; iguales en la app (`perfilDeCultivo`) y en Apps Script (`perfilHuertaFila_`). El formulario exige riego, fertilización y plagas > 0.
2. **Sync del Sheet a Firestore:** `sincronizarPlantasAFirestore` incluye los campos de huerta **solo en filas con `categoria = 'huerta'`**, para no pisar valores de Firestore con celdas vacías si el Sheet todavía no tiene esas columnas.
3. **Apps Script inicializa las fechas de un cultivo nuevo** (`Próxima fertilización`, `Próxima revisión de plagas`, `Último riego` = siembra + intervalo) en `actualizarFichaPlantas`, porque `guardarPlantaSheet` no toca las columnas I–S.
4. **Ids de eventos únicos:** el riego agrupado registra varios eventos en el mismo milisegundo; `registrarEventoPlanta` pasa a usar `idLocal('ev')` (`'ev' + Date.now() + contador de 3 dígitos`), que sigue cumpliendo `ID_LOCAL_PLA`.
5. **Tarea de cosecha:** el toque › usa `confirm()` (mismo patrón que los borrados existentes) y cierra el cultivo como cosechado.
6. **Cache del service worker:** los módulos same-origin son cache-first; cada cambio futuro en `huerta-catalogo.js` exige subir la versión de `CACHE` en `sw.js` (queda comentado en el archivo).

```js
// Catálogo de la huerta y funciones puras (sin DOM ni Firebase). Lo importa
// index.html y lo prueba scripts/test-huerta.mjs en Node.
// Cada vez que se cambie este archivo hay que subir la versión de CACHE en sw.js.

export const CATALOGO_HUERTA = [];   // se completa en la Tarea 2

export const numero = v => (v === '' || v == null || isNaN(+v)) ? null : +v;
const dia = s => (s ? new Date(String(s).slice(0, 10) + 'T00:00:00') : null);
const MS_DIA = 86400000;

export const CERRADOS = ['cosechado', 'terminado'];
export const estaCerrado = p => !!p && CERRADOS.includes(p.estadoCultivo);

// Valores de respaldo si a un cultivo manual le falta algún dato. Apps Script usa
// los mismos (perfilHuertaFila_ en codigo.gs).
export const PERFIL_POR_DEFECTO = { riegoVerano: 3, riegoInvierno: 5, diasFert: 30, diasPlagas: 7 };

// Perfil de un cultivo a partir de su "foto" (lo copiado del catálogo al agregarlo).
export const perfilDeCultivo = p => ({
  tipo: 'Exterior',
  riegoVerano:   numero(p.riegoVerano)   ?? PERFIL_POR_DEFECTO.riegoVerano,
  riegoInvierno: numero(p.riegoInvierno) ?? PERFIL_POR_DEFECTO.riegoInvierno,
  diasFert:      numero(p.diasFert)      ?? PERFIL_POR_DEFECTO.diasFert,
  diasPlagas:    numero(p.diasPlagas)    ?? PERFIL_POR_DEFECTO.diasPlagas,
  fertMesIni: null, fertMesFin: null, tempMin: null, podaDias: null,
});

// Días desde la siembra (fechaP). `hoy` es un Date a medianoche local.
export const diaDeCultivo = (p, hoy) => {
  const s = dia(p.fechaP);
  return s ? Math.round((hoy - s) / MS_DIA) : null;
};

export const faseCultivo = (p, hoy) => {
  if (estaCerrado(p)) return 'cerrado';
  const d = diaDeCultivo(p, hoy);
  const dc = numero(p.diasACosecha), dt = numero(p.diasATrasplante);
  if (p.ciclo === 'perenne' || !dc || d == null) return 'crecimiento';
  if (dt && !p.fechaTrasplante) return d < dt ? 'semillero' : 'por-trasplantar';
  if (d >= dc) return 'cosecha';
  if (d >= dc - 7) return 'cosecha-proxima';
  return 'crecimiento';
};

export const progresoCosecha = (p, hoy) => {
  const d = diaDeCultivo(p, hoy), dc = numero(p.diasACosecha);
  if (p.ciclo === 'perenne' || !dc || d == null) return null;
  return Math.max(0, Math.min(1, d / dc));
};

export const diasParaCosecha = (p, hoy) => {
  const d = diaDeCultivo(p, hoy), dc = numero(p.diasACosecha);
  if (p.ciclo === 'perenne' || !dc || d == null) return null;
  return dc - d;
};

export const fechaCosechaEstimada = p => {
  const s = dia(p.fechaP), dc = numero(p.diasACosecha);
  if (!s || !dc) return null;
  return new Date(s.getTime() + dc * MS_DIA);
};

// ── Catálogo ─────────────────────────────────────────────────────────
export const buscarCultivo = clave => CATALOGO_HUERTA.find(c => c.clave === clave) || null;

export const perfilDeCatalogo = clave => {
  const c = buscarCultivo(clave);
  if (!c) return null;
  return {
    clave: c.clave, nombre: c.nombre, ciclo: c.ciclo,
    riegoVerano: c.riegoVerano, riegoInvierno: c.riegoInvierno,
    diasFert: c.diasFert, diasPlagas: c.diasPlagas,
    diasATrasplante: c.diasATrasplante, diasACosecha: c.diasACosecha,
    mesesSiembra: c.mesesSiembra.slice(),
  };
};

export const fichaDeCatalogo = clave => { const c = buscarCultivo(clave); return c ? c.ficha : null; };

// Una clave desconocida (o 'manual') no genera aviso de época.
export const enEpocaDeSiembra = (clave, mes) => { const c = buscarCultivo(clave); return !c || c.mesesSiembra.includes(mes); };
```
